## 雷电将军实现核对（Trae 实现后，最高复杂级别）

逐行核对结论：**零 bug，实现正确**。这是唯一一个「动被动框架接口」的棋子——新增两个钩子。

### 框架缺口修复（两个新钩子，默认空实现，现有被动零改动）
- IPassiveEffect 新增 `OnAllyUltimateCast(owner, caster)`（己方开大广播）+ `OnAllyAttackHit(owner, ally, target, damage, source)`（己方攻击命中广播）
- 三个广播调用点：UseUltimateCore Execute 后（大招释放）/ AttackPiece 尾部（source=damageSource 参数）/ ApplyIncomingDamage 尾部（仅 damageType==Ultimate）
- 广播范围：`TurnManager.Model.GetPieces(阵营)` 全体**存活**棋子（IsDead/IsDestroyed 跳过）——死亡自然失效，无需额外判断

### 关键设计决策（都做对了）
1. **新增独立钩子而非复用 OnDamageDealt**：OnDamageDealt 仅普攻路径触发，若复用它，DoubleStrike/FrostBreak/Domain 会被大招误触发。Trae 选新增 OnAllyAttackHit 独立广播，既有钩子语义零变化。
2. **协同递归防护**：static `_striking` 重入守卫——协同攻击走 AttackPiece 会再次广播 OnAllyAttackHit，守卫期间本被动 L68 直接 return（效果1回能+效果2协同都被拦），finally 复位。验证时序：_striking=true → AttackPiece 同步执行 → 内部 L338 广播 → 本被动 _striking 拦截 → 返回 → finally 复位。
3. **含自己协同 / 回能不含自己**（用户拍板）：效果2 协同 Attack/Splash/Ultimate 都触发（含自己普攻/大招）；效果1 回能只认 `ally==owner && source==Attack`（真普攻主段）；StormEye 回能 `ReferenceEquals(caster,owner) return`（不含自己开大）。
4. **溅射 source 正确传递**：元素溅射 AttackPiece 传 `damageSource:Splash`（L589）→ 广播 Splash → 效果2 协同触发、效果1 回能不触发（source!=Attack）；非元素溅射走 ApplyIncomingDamage(Splash) 不广播（非 Ultimate）。
5. **「本次大招命中不触发协同」**：MusouStrike 激活放伤害段之后——首次释放伤害段广播时 _turnsRemaining==0 不协同；但协同持续期间第二次放大招，伤害段会正确触发协同（「大招触发协同」语义）。

## 带元素伤害跳字颜色修复（8-20 凌晨）

用户反馈：杜林溅射（火物理）、克洛琳德路径（雷物理）跳字是白色，但应为元素色。

核对结论：**底层伤害计算正确（带元素），只有跳字显示层丢元素色**。
- 根源：普攻走 AttackPiece 跳字用 `GetElementDamageColor`（元素色）；被动/大招走 `ApplyIncomingDamage` 统一入口跳字用 `GetDamageKindColor`（物理=白）。带元素的被动/大招伤害因此显示白色。
- 修复方向（已出提示词 `带元素伤害跳字颜色修复_Trae提示词.md`）：带元素伤害→元素色（火/水/雷/冰）；无元素伤害（反伤/感电DoT/超载爆炸/非元素溅射）→保持伤害类型色。
- 带元素调用点 11 处（FlameNova/VoltPath/ThunderSweep两段/FireSlash/FlameLance/FrostArrow三档/Domain/Blizzard/FrostFeast/MusouStrike/Puppet），无元素 4 处（Thorns/DoT/超载/非元素溅射）。
